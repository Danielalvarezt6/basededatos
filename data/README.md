# Datos brutos (no incluidos en Git)

Coloca aquí el archivo **`dataset.csv`** del Skill Builder / ASSISTments (aprox. 2,8 GB).

- Descarga sugerida: [Kaggle — Skillbuilder Data 2009-2010](https://www.kaggle.com/datasets/nicolaswattiez/skillbuilder-data-2009-2010)
- Ruta esperada por el script de carga: `data/dataset.csv`

El archivo está listado en `.gitignore` para no subirlo a GitHub.

Luego ejecuta desde la raíz del repositorio:

```powershell
python scripts/cargar_assistments_completo.py
```
